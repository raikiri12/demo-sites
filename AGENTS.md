# Проект: демо-лендинги для местных бизнесов
Статус и следующий шаг - в PLAN.md. Читай его в начале каждой сессии, обновляй в конце шага.
Источник списка бизнесов - "local businesses.md" (одна строка = ссылка 2ГИС + комментарий).

## Правила данных
- Никогда не выдумывать данные бизнеса: название, адрес, телефон, часы, услуги, цены. Нет данных - поле пустое, блок на странице скрывается.
- Цены только из data/research/{slug}.json (prices), с пометкой "от".
- Отзывы только пересказом 1-2 фразами, без имён авторов. Поле complaints на сайт не выносить.
- Фото только из data/photos/{slug}/ (фото "от владельца" и рекламные превью организации). Никогда не ссылаться на картинки с внешних сайтов. Папка пустая - визуал из типографики и CSS/SVG.
- На каждой странице: meta robots noindex,nofollow и плашка внизу: "Демо-концепт сайта для {название}. Подготовлено Вячеслав как предложение, не является официальным сайтом. Удалим по первой просьбе." Если есть фото - добавить "Фото из открытой карточки организации".
- Цветочная витрина: квадратные миниатюры, 4 в ряд на 360px, подписи 12px максимум в 2 строки, поиск, сортировка и "Ещё"/"Свернуть". Блок "Сколько стоит" у цветов не выводить; блок статистики не добавлять.
- Для витрины открыть все фото и исключить любые с людьми, включая руки и отражения. Подходящие номера хранить в showcase_photo_indexes; при нуле фото витрину скрывать.
- Всем страницам нужны favicon и og:title/og:description/og:image: первое фото бизнеса или типографическая OG-заглушка темы с реальным названием.
- Микроанимации только на CSS: появление секций и hover; на страницах без фото - параллакс паттерна и watermark. В автопрайсе названия максимум в 2 строки.
- В Hero при >=1024px миниатюры под телефоном выравнивать по левому краю текстовой колонки; мобильную раскладку не менять.

## Стек
Статика. Node.js, scripts/build.mjs собирает dist/ из data/businesses.csv + content/{slug}.json + templates/. Без фреймворков и CDN, кроме виджета Яндекс Карт. Фото через sharp в webp до 1600px. Мобильная вёрстка в приоритете (360px), телефоны через tel:.

## Экономия токенов
- Одна задача - одна сессия. Не перечитывай уже прочитанные файлы; сначала Grep/Glob, потом Read нужного фрагмента.
- Не выводи содержимое файлов в ответ - только путь и что изменилось.
- План 3-5 пунктов, итог 3-5 пунктов. Без пересказа.
- Не запускай сборку и проверки повторно без изменений. Браузер и скриншоты - только по просьбе.
- Сабагенты возвращают отчёт до 3 строк.
