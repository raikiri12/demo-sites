# kit-kimi: установка за 5 минут

Адаптация кита "19 сайтов за 4 минуты" под Kimi Code. Логика, роли и промпты - из оригинала, поменялась только механика запуска.

## Что сделать один раз

1. **Создай папку проекта** и скопируй туда из этого кита:
   - `AGENTS.md`, `PLAN.md`, `PROMPTS.md` - в корень проекта
   - `tools/` и `sales/` - как есть
2. **Установи агентов**: скопируй 4 файла из `agents/` в `C:\Users\MASTER\.kimi-code\agents\` (плоско, без вложенных папок; имена файлов = имена агентов).
3. **Заполни плейсхолдеры**: `{ГОРОД}`, ниши и `{твоё имя}` в плашке (в `AGENTS.md`, раздел "Правила данных", и в `PLAN.md`).
4. **Настрой модели в Kimi Code**:
   - основная (primary): `/model` → **K3** - на ней шаги 1-2, 4 и 6 (весь рабочий пайплайн);
   - вторичная (secondary): команда `/secondary-model` → **K2.7 Code Highspeed**. На ней пойдут biz-researcher и qa-checker (экономия как у Haiku в оригинале);
   - эталон (шаг 3): `/model` → **K3.1 Pro**, `/effort` → high.
   - Модель по умолчанию в приложении - K2.8 Preview: для рабочих шагов переключайся на K3 и effort low, иначе уйдёшь в Max-расход.
5. **Проверь, что агенты подхватились**: попроси запустить любого агента - он должен быть найден в `~/.kimi-code/agents/`.

## Порядок работы

Идёшь по `PROMPTS.md` шаг за шагом. Ключевое:

- **Перед шагом** выставляешь модель и effort (`/model`, `/effort`) по таблице в начале PROMPTS.md; **после шага** - `/clear` или новая сессия.
- **Шаг 3 (эталон)** - единственное место, где переключаешься на K3.1 Pro с effort high. После - обратно на K3.
- **Шаги 2 и 4 (рой)** - перед запуском включи `/swarm`, агенты стартуют параллельно.
- **Шаг 2.5 (фото)** - первый прогон проверь глазами: если 2ГИС покажет капчу, стоп, дальше по обстановке. Нужен Playwright: `pip install playwright`, `playwright install chrome`.
- **Шаг 6 (деплой)** - понадобится `gh` (GitHub CLI) с авторизацией.

## Что осталось от оригинала без изменений

- все промпты агентов (запреты, форматы, лимиты отчётов);
- правила данных: ничего не выдумывать, цены только из research, плашка "демо-концепт", noindex;
- пайплайн 7 шагов и sales-материалы;
- `tools/no_site_leads.py` - без правок.

Подробности "почему так" - в `HUB-GUIDE.md`.
